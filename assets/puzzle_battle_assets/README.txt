Puzzle Battle - extracted playmat assets
========================================

This pack contains cropped PNG pieces from the generated playmat reference.
Included: 5 opponent slots, 5 player slots, 16 central card backs, 4 HP/Energy panels,
the End Turn button, four decorative corner crops, and the full reference image.

Important: the source was a single flattened image, so these are rectangular crops and
may include pixels from the original background. They are useful as a first-pass asset
pack, but are not individually reconstructed transparent sprites. For a production game,
consider redrawing the UI elements as independent transparent PNG/SVG assets.
